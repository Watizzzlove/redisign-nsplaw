# NSP Law — Prototype (LMNTRIX Cyber-Tech Legal Edition)

Интерактивный standalone прототип главной страницы в стилистике референса **LMNTRIX** (темная технологичная тема, светящиеся неоновые акценты циан, Bento Grid `01/04`, бегущая строка инсайтов и интерактивный Canvas).

## 💎 Особенности
* **Автономность:** работает без Node.js / npm — достаточно открыть `index.html` в любом современном браузере.
* **Интерактивный Canvas:** магнитная сетка частиц на фоне, соединяющаяся со световым курсором.
* **Bento-карточки практик `01/04` — `04/04`:** неоновые рамки, метрики миллиардных споров, 3D-иконки.
* **Живая бегущая строка Telegram:** актуальные прецеденты и новости практики.
* **Модальное окно:** конфиденциальный бриф с партнером с селектором практики.

## 🚀 Запуск
Просто откройте файл `index.html` двойным кликом в браузере (Chrome, Edge, Safari, Firefox).
